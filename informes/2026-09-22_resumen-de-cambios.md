# Resumen de la revisión de Society

Estado: vigente · revisión documental. Fecha de revisión: 2026-09-22.
Ámbito / a quién obliga: producto Society; síntesis de cambios del 22 de septiembre. Fuentes: archivos del proyecto y comprobaciones indicadas en esta auditoría. Índice único: [README](../README.md).

Se ejecutó el encargo de limpieza y sistema creativo sobre el repositorio. Society queda definido como producto; Torre de Vega aporta evidencia y preferencias de cliente. Esta entrega es documentación de diseño, no una aplicación implementada.

**Qué cambió.** README raíz es el único índice vigente y sus §§15–16 reflejan el repositorio resultante. Los documentos Markdown tienen estado, revisión, ámbito y fuentes; la fecha editorial no refecha ensayos. Se archivaron la idea inicial, el inventario antiguo, el PDF congelado y la skill de After Effects, conservando copias de los índices/flujo previos. Se repararon enlaces y se señalaron recursos externos ausentes.

Se corrigieron las reglas activas: personas permitidas, ficha aprobada para protagonistas, keyframes 2K para el cliente, montaje Remotion y continuidad visual que se verifica, sin garantías falsas por usar dos imágenes de anclaje.

**Tres diseños nuevos.** [Producción](higgsfield/05-automatizacion-de-produccion.md) define capacidades versionadas, cadena completa, plazos propios, costes, límites de reintentos, respuestas tardías, dos puertas humanas por pieza, linaje, QA y publicación. [Dirección visual](Society_metodo_direccion_visual.md) fija biblia, casting, fichas y consistencia; Canvas queda como apoyo opcional. [Cerebro estratégico](Society_cerebro_estrategico.md) conecta negocio, objetivo, guion y plano; selecciona diez recursos y acota el aprendizaje y el TFG.

**Qué se descartó.** AE como ruta activa; enlaces a diagramas inexistentes; bloqueo indefinido por proveedor; equivalencia automática entre MCP y REST; convertir scores del predictor o «ganar 2 de 3» en prueba de ventas; bandits y automatización de Canvas como requisitos de enero. Se conservó la evidencia histórica con límites de interpretación.

**Qué quedó verificado.** Catálogo y estimaciones gratuitas: Nano 2K, 2 cr; Kling pro 3 s sin audio, 5,25 cr; Seedance omni 1080p 10 s sin audio, 120 cr, sin referencias concretas en el preflight. Son presupuestos de parámetros, no pruebas de generación. Se contrastaron documentación técnica, Canvas público/ayuda y actividad/licencias de siete repositorios.

**Qué queda abierto.** Conversión económica MCP sin factura o cotización monetaria; acceso de servicio y aislamiento; ruta equivalente con referencias; fal; Canvas privado/API; permisos sociales; ensayo visual, tiempo humano y render. Meta no pudo revalidarse por 429. No se gastaron créditos ni se publicó contenido. Víctor conserva la implementación del código del TFG.

La [auditoría](2026-09-22_auditoria-de-continuidad.md) detalla contradicciones, traslados y verificaciones. El siguiente paso es implementar un canal, un piloto, imágenes/posts/historias y una ruta de Reel cualificada, con medición comparable y presupuesto cerrado.
