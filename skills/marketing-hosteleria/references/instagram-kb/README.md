# Instagram Skill Hostelería — Knowledge Base

Knowledge base completa para hacer crecer cuentas de Instagram de restaurantes, bares, coctelerías, pizzerías, cafeterías y food trucks en España, y convertir seguidores en clientes reales (reservas, visitas, pedidos). Construida con Deep Research 2025-2026: algoritmo actual, estrategia de contenido, configuración técnica, benchmarks, herramientas, workflows de automatización, plantillas listas para usar y recursos verificados.

## Quick start (5 minutos)

1. Abre **[RESOLVER.md](RESOLVER.md)** y busca tu objetivo actual — te dice exactamente qué archivos leer.
2. Si es tu primera vez con esta KB, lee en este orden:
   - [00-algoritmo/README.md](00-algoritmo/README.md) — entiende cómo decide Instagram qué mostrar en 2026
   - [02-configuracion-tecnica/README.md](02-configuracion-tecnica/README.md) — checklist de configuración óptima (hazlo antes de publicar nada)
   - [01-estrategia-contenido/README.md](01-estrategia-contenido/README.md) — qué formato y narrativa usar
   - [03-hosteleria-nichos/README.md](03-hosteleria-nichos/README.md) — adapta la estrategia a tu tipo de negocio
3. Usa [07-plantillas-prompts/](07-plantillas-prompts/) para publicar tu primera semana de contenido sin partir de cero.
4. Si vas a generar imágenes con IA, lee primero [10-skill-integration/directoria-integration.md](10-skill-integration/directoria-integration.md) — conecta esta skill con [DirectorIA Cloud](../../../directoria/SKILL.md) para generar desde fotos reales, no platos inventados.
5. Configura la rutina semanal de [06-workflows-automatizacion/README.md](06-workflows-automatizacion/README.md) para sostener el ritmo.
