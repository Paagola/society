# README — Recursos para seguir aprendiendo

## TL;DR
- Esta carpeta reúne recursos verificados (a fecha de septiembre 2026) para formarse en marketing de Instagram/redes sociales aplicado a hostelería.
- Empieza siempre por los cursos gratuitos (`courses-free.md`) antes de plantearte pagar por formación.
- `tools-directory.md` enlaza únicamente herramientas activas y verificadas — no listamos herramientas descontinuadas.
- Los canales de YouTube y blogs/newsletters de `youtube-channels.md` y `blogs-newsletters.md` están seleccionados por publicar contenido actualizado y en español (o con gran relevancia aunque estén en inglés).
- Todos los enlaces han sido comprobados mediante búsqueda web en el momento de escribir este documento; aun así, revisa la URL antes de compartirla porque el contenido online cambia con frecuencia.

## Cómo usar esta carpeta
1. Si vas a formarte desde cero en gestión de redes para hostelería, empieza por `courses-free.md` (HubSpot Academy + Metricool Academy + Meta Blueprint).
2. Si necesitas una certificación reconocible para un CV o propuesta comercial, revisa `courses-paid.md` para saber cuándo compensa pagar.
3. Suscríbete a 2-3 recursos de `youtube-channels.md` y `blogs-newsletters.md` para mantenerte al día de cambios de algoritmo y formatos.
4. Usa `tools-directory.md` como catálogo de referencia rápida cuando necesites una herramienta concreta (programación de posts, diseño, analítica, IA).

## Errores comunes
- ❌ Pagar por un curso antes de agotar las opciones gratuitas equivalentes.
  ✅ Empieza gratis; paga solo cuando necesites certificación oficial, soporte 1:1 o contenido muy especializado.
- ❌ Seguir canales/blogs desactualizados que ya no publican.
  ✅ Verifica la fecha de la última publicación antes de considerarlos una fuente activa.
- ❌ Confiar en un enlace sin comprobarlo antes de enviarlo a un cliente.
  ✅ Abre el enlace y confirma que sigue activo antes de compartirlo en una propuesta o informe.
