# Herramientas para gestionar Instagram en hostelería

## TL;DR
- No existe una única herramienta "todo en uno" perfecta: el stack recomendado combina Meta Business Suite (gratis, base) + una herramienta de programación/analítica de pago si el negocio tiene varios locales + un generador de imágenes IA para cubrir huecos de contenido.
- Para un solo restaurante con presupuesto ajustado, el stack mínimo viable es: Meta Business Suite (gratis) + Metricool o Buffer en plan gratuito/básico + un editor de fotos móvil (Lightroom, VSCO).
- Para negocios con varios locales o agencias que gestionan varias cuentas, Metricool o Sprout Social justifican su coste por la gestión multi-marca y reporting.
- El scraping de datos de Instagram (para benchmarking de competencia) debe hacerse solo sobre datos públicos y con herramientas que respeten los términos de servicio; el uso agresivo expone a bloqueos legales y de cuenta.
- La automatización con Zapier/Make/n8n permite conectar Instagram con reservas, CRM y email marketing, pero requiere vigilar los límites de la API (ver [[../02-configuracion-tecnica/security-privacy.md]]).

## Stack recomendado por tamaño de negocio

**Restaurante/bar independiente (1 local, presupuesto bajo):**
- Meta Business Suite (gratis) para programación y bandeja de entrada
- Metricool plan gratuito o Buffer Essentials (~5-6€/mes) para analítica extra
- App de edición móvil (Lightroom Mobile, VSCO) para fotos
- Canva o una app de IA de imágenes puntual para piezas gráficas (cartas del día, promociones)

**Grupo de 2-5 locales o restaurante con más presupuesto:**
- Metricool (plan Starter/Advanced) o Buffer Team, para gestionar varias cuentas desde un panel
- Iconosquare si se prioriza analítica avanzada y comparativa con competencia
- Herramienta de automatización (Make o n8n) para conectar reservas, WhatsApp y email marketing

**Cadena o agencia que gestiona múltiples cuentas de hostelería:**
- Sprout Social o Hootsuite (gestión de equipo, aprobaciones, reporting a cliente)
- Apify o ScrapFly para monitorización de competencia a escala
- n8n autoalojado para automatizaciones de alto volumen a bajo coste
